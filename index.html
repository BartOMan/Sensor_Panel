What location could have reported

Available through the browser, not shown above

  • Altitude, meters above the WGS84 ellipsoid (often null without GPS)
  • Altitude accuracy, meters
  • Heading, degrees from true north, only while moving
  • Speed, m/s, only while moving
  • Timestamp of the fix

In a raw GNSS/NMEA stream, never exposed to web pages

  • Satellites in view and in use, per-satellite PRN, elevation, azimuth
  • Signal strength (SNR / C/N₀) per satellite
  • Dilution of precision: HDOP, VDOP, PDOP
  • Fix type and quality: none / 2D / 3D, DGPS, RTK
  • Constellation: GPS, GLONASS, Galileo, BeiDou, QZSS
  • GNSS UTC time, geoid separation, magnetic variation

Wi-Fi-only iPads have no GNSS receiver; their position comes from Wi-Fi and network lookup, so accuracy is typically tens of meters.

Not available in iPadOS Safari

  • Raw magnetometer (µT per axis), only the derived compass heading
  • Barometer / altimeter pressure
  • Ambient light sensor (camera proxy used above)
  • Proximity sensor
  • Battery level and charging state
  • Generic Sensor API classes (Accelerometer, Gyroscope, etc.) at custom sample rates
  • Pedometer / activity data
  • LiDAR / Face ID depth
